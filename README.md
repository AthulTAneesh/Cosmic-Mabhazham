# Beyond the Mission

A dependency-free, scroll-driven website based on the supplied presentation. It turns the presentation’s sequential story into one continuous scene: Earth and Mars transition into Opportunity’s extended mission, a dust storm, Voyager’s interstellar journey, and the Pale Blue Dot.

Debugged, Tested and Improved using ChatGPT

## Run it

Open `index.html` in a modern browser. No build step, package manager, or local server is required.

## Included

- `index.html` — semantic story structure
- `styles.css` — responsive artwork, type, and transition styling
- `script.js` — scroll-progress scene controller
- `assets/ppt/media/` — selected visual assets carried forward from the supplied presentation
